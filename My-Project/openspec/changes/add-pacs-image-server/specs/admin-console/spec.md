# Spec Delta

## Purpose

规定信息科管理员用来运行和维护 PACS 的入口：一个图形管理控制台和一套命令行。二者都能完成服务启停、白名单维护、影像库浏览、完整性核查、告警处理和审计查看。操作员身份只记录、不认证。

## ADDED Requirements

### Requirement: R20 管理控制台与命令行
系统 SHALL 提供 PyQt5 管理控制台，含六个页面：服务状态（AE、端口、运行状态、活动关联数）、白名单、影像库（患者 / 检查 / 序列 / 实例树加预览）、完整性核查、告警（可确认）、审计（可校验、可导出）。系统 SHALL 提供等价的 CLI 命令。界面 MUST NOT 提供修改或删除审计记录的入口；非法的白名单输入 SHALL 被拒绝并提示。查看影像预览与导出审计 SHALL 写入审计。

#### Scenario: TC-R20-P1 离屏冒烟：各页面显示测试数据
- **WHEN** 在 QT_QPA_PLATFORM=offscreen 下用有测试数据的 runtime 打开控制台并依次切换六个页面
- **THEN** 每个页面都显示对应数据（白名单行数、患者树节点、告警行、审计行都大于 0），并为每个页面保存一张截图

#### Scenario: TC-R20-N1 界面拒绝非法白名单输入
- **WHEN** 在控制台的白名单表单中提交 17 个字符的 AE Title
- **THEN** 显示错误信息，白名单行数不变

#### Scenario: TC-R20-N2 审计页面没有修改或删除入口
- **WHEN** 检查审计页面上的全部按钮和表格编辑属性
- **THEN** 不存在删除或编辑类按钮，表格不可编辑
